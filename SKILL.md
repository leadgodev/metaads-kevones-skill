## Como usar

1. Não leia os 109 arquivos de uma vez. Abra `references/INDICE.md`, ache o
   módulo relevante pro que você precisa decidir agora.
2. Leia só as aulas daquele módulo.
3. Módulos-chave por situação:
   - **Já tem oferta, não escala** → `05-meta-ads-2026-andromeda` (configurar conta) → `08-metodologia-de-escala` (ROAS sem subir CPA, escala horizontal/vertical) → `09-empilhamento-de-bidcap`.
   - **Não sabe se a oferta converte** → `06-sua-oferta-converte`.
   - **Testar e diagnosticar gargalo** → `07-teste-otimizacao-validacao` (estrutura de campanha por orçamento + painel de métricas).
   - **Criar oferta nova / vender em dólar** → `12-lowticket-em-dolar-na-pratica` (introdução → espionagem de ofertas → criativos → subir campanha internacional).
   - **Criativos** → `15-masterclass-criativos-milionarios` (TikTok, diretos, catálogo, dicas).
   - **Sofrendo bloqueio/restrição no Meta Ads** → `18-masterclass-contencao`.
   - **Iniciante absoluto** → `03-curso-trafego-do-zero`.
   - **Infoproduto do zero** → `04-criando-infoproduto` + `16-desafio-do-infoproduto`.
   - **Prestação de serviço / gestão de tráfego pra cliente** → `17-curso-agencia-milionaria`.
   - **E-commerce/delivery** → `19-trafego-para-ecommerce`.
